# Planeja BNCC Computação

Aplicativo web estático baseado na matriz de integrações entre componentes curriculares e BNCC Computação.

## Como abrir

Abra `index.html` no navegador. Os planos salvos ficam apenas no navegador utilizado (armazenamento local).

## Atualizar a base

Para gerar novamente `data.js` a partir da planilha, execute `work/extract_bncc_data.py` com o Python que possui `openpyxl`.
